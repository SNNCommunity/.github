Input pattern

LIF: V(t+1) = V(t) + [I(t) − V(t)] / τ. IF: V(t+1) = V(t) + I(t) / τ. Both use 1 ms steps and a hard zero-reset after crossing Vth. IF uses τ as an integration scale, not a decay time constant. All voltages and inputs are normalized; this is not benchmark or biological evidence. Model specification ↗
