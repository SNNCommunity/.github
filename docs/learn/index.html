GUIDED CURRICULUM

From spikes to reproducible results.

These are learning objectives and reading routes, not SNNCommunity-issued courses or certifications.

STAGE / 01

Membrane dynamics and spike generation

Understand integrate-and-fire dynamics, leak, thresholds, reset rules and discrete-time simulation. Compare LIF and IF under controlled inputs.

  • Derive the update rule and distinguish membrane leakage from integration gain.
  • Check spike times, membrane traces and the effect of timestep choice.
Run the interactive LIF/IF model ↗Read snnTorch tutorials ↗
STAGE / 02

Training spiking networks

Move from neuron dynamics to multi-layer SNNs, time-dependent state updates and surrogate-gradient training.

  • Explain forward spiking decisions and the surrogate-gradient backward path.
  • Compare temporal state handling and resets between training sequences.
Explore SpikingJelly documentation ↗Explore Norse components ↗
STAGE / 03

Event-based data and systems

Understand sparse asynchronous events and the choices involved in converting event streams into tensors or temporal representations.

  • Inspect sensor events, time bins and transformations.
  • Understand how event preprocessing changes latency and temporal fidelity.
Explore Tonic event data tools ↗
STAGE / 04

Evaluation and reproducibility

Record timestep, datasets, preprocessing, network configuration, runtime and hardware before comparing SNN results.

  • Separate author-reported numbers from independently reproduced measurements.
  • Understand task-level metrics and system-level efficiency constraints.
Read NeuroBench documentation ↗Review the experiment workspace ↗
