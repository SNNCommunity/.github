# Support and Community Help

SNNCommunity is in its **initial setup phase**. Please use the most specific channel currently available.

| Topic | Where to ask |
| --- | --- |
| Corrections to our organization profile or community policy | [Open an issue in this repository](https://github.com/SNNCommunity/.github/issues) |
| Changes to an existing code repository | Open an issue in that project's own repository |
| Questions about third-party tools such as snnTorch or SpikingJelly | Start with the official tool's documentation and support channels |
| Proposed SNN paper or tutorial resource | Open a properly sourced proposal or issue |
| Sensitive security or conduct report | Read [SECURITY.md](SECURITY.md) or [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md); do **not** publish confidential details |

## How to ask an effective technical question

Include the task, minimal reproducer, expected versus observed behavior, software versions, device type, relevant logs, and attempts already made. Remove access tokens, emails, proprietary datasets, and confidential information.

For research questions, add the paper link and describe the exact equation, experiment, or claim you want to discuss. When comparing benchmarks, include evaluation protocols, hardware, seeds, and time-step configuration.

## Community discussion hub

An organization-wide Discussions hub is **planned but is not yet announced as available**. Once launched, this page will link directly to it. Until then, do not assume that an unlinked discussion board or social account is officially operated by SNNCommunity.

Please respect the [Code of Conduct](CODE_OF_CONDUCT.md) when seeking support.
